# SWCS 繪圖工具（Standard Work Combination Sheet Tool）

單一 HTML 檔的**標準作業組合票（SWCS / 山積表姊妹圖）繪製工具**——輸入各站步驟秒數，自動畫出 TPS 標準作業組合票：手作業、機械自動加工、走動、等待的完整時間線。免安裝、免網路、開瀏覽器即用。

## 功能特色

- **自動繪圖**：黑實線（手作業）、紅虛線（自動加工）、雙綠細線（走動）、灰點線（等待），人員軌跡連續不中斷
- **等待浪費自動偵測**：
  - 💚 **人等機**（人員閒置）：綠底爆炸圖＋等待秒數
  - 💛 **機等人**（機台閒置）：黃底爆炸圖＋閒置秒數 — CNC 改善機會一眼可見
- **一人多機重複巡迴**（作業路徑模式）：同一站可多次造訪，軌跡跳回同列（傳統 SWCS 畫法），每段走動秒數獨立設定
- **統計自動計算**：各循環 Cycle Time、CT vs Takt 差異、人等機／機等人明細與合計、Capacity
- **A3 拼貼列印**：自動分頁、字體放大至肉眼可讀，印出後拼貼成完整牆面大圖；亦可另存 PDF
- **編輯體驗**：Excel 貼上匯入、步驟插入／排序、Ctrl+Z 復原、滑鼠拖曳平移圖面、資料自動保存（localStorage）

## 使用方式

1. **線上**：開啟 GitLab Pages 網址（部署後填入）
2. **離線**：下載 `index.html`，雙擊用 Edge / Chrome 開啟
3. 按「載入範例(Demo)」看示範案例（1 人 5 機），或載入 `samples/swcs-demo-sample.json`
4. 詳細操作見 [docs/manual.html](docs/manual.html)（圖文說明書）

## 資料隱私

所有資料只存在**你自己的瀏覽器**（localStorage）與你另存的 JSON 檔，不會上傳到任何伺服器。
