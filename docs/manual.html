SWCS 繪圖工具 使用說明（圖文版）

本工具用於製作 標準作業組合票（Standard Work Combination Sheet）：輸入各站步驟秒數，自動畫出手作業／機械加工／走動／等待的時間線圖。單一 HTML 檔、免安裝、免網路，用 Edge 或 Chrome 開啟即可。

目錄
1. 開啟工具｜2. 載入範例資料｜3. 介面總覽｜4. 填寫基本資料｜5. 輸入步驟資料｜6. 從 Excel 貼上匯入｜7. 產生圖形與判讀｜8. 輸出 PDF｜9. 儲存與開啟資料檔｜10. 常見問題

1開啟工具

  1. 把收到的 zip 檔解壓縮到自己電腦（例如桌面）。
  2. 對 SWCS繪圖工具.html 按兩下，瀏覽器（Edge / Chrome）會自動開啟。
⚠ 不要在壓縮檔視窗裡直接點開，一定要先解壓縮，否則資料無法自動保存。
✔ 不需要安裝任何軟體、不需要網路、不會跳資安警告。

2載入範例資料（第一次使用建議先做）

壓縮包內附 swcs-demo-sample.json（示範產線，1 人 5 機）。

  1. 按工具列的 「開啟資料檔」。
  2. 在跳出的視窗選擇 swcs-demo-sample.json → 開啟。
  3. 畫面會出現 10 個工作站的完整資料與 SWCS 圖，可以此為範本修改成自己的案子。

4填寫基本資料

欄位說明
表單標題顯示在圖最上方的標題
Product / Operator #產品（區域）名稱、作業人員編號
Takt time (sec)節拍時間；圖上會畫紅色虛直線供比對
Available time (sec)每班可用時間；用來自動計算 Capacity（產能）
循環數要畫幾個作業循環（1~6）；畫 2 個以上才能看出機台等待
時間軸縮放圖的橫向密度（px/秒），加工時間長可調小

Cycle time 與 Capacity 由程式依模擬結果自動計算，不用填。

排序規則：

  • 站與站之間：依「步驟編號」中「-」前面的數字決定作業順序（1-x 最先做，2-x 次之…）。
  • 站內：依表格列的順序由上而下執行。標準排法：取出工件 → 放置工件 → 機械加工 → 吹/清潔 → 走動。

秒數填法：手作業填 Manual、機械自動加工填 Auto、走動填 Walk，一列填一種即可。 機械加工的 Auto 也可以直接填在「放置工件」那一列（放置後按開關的情境），紅虛線會接在黑線正後方。

6從 Excel 貼上匯入（已有 SWCS Excel 檔時）

  1. 在 Excel 框選資料範圍（原 SWCS 模板選 A9:K88），按 Ctrl+C 複製。
  2. 回到工具按「從 Excel 貼上匯入」，在跳出的視窗按 Ctrl+V 貼上。
  3. 按「匯入」，資料自動轉入（站號、多行機台描述、合併儲存格都能正確處理）。
▼ 貼上匯入視窗（示意）

從 Excel 貼上匯入

支援兩種格式：① 原 SWCS 模板 A~K 欄　② 簡易 7 欄（站號, 機台描述, 步驟編號, 步驟說明, Manual, Auto, Walk）
取消匯入
⚠ 匯入後請檢查各站列順序是否為「取出 → 放置 → 加工 → 吹 → 走動」，舊檔若順序不同，用 ↑↓ 調整。

▼ 圖形範例（一個工作站的軌跡）

黑色實線手作業（Manual）：取出、放置、吹屑等
紅色虛線機械自動加工（Auto）：從「放置工件」結束（按開關）那一刻開始

圖形下方的統計表會列出各循環的 Cycle Time、等待明細（哪一站等幾秒＝瓶頸線索），以及最後循環 CT 與 Takt 的差異（紅字=超過節拍、綠字=有餘裕）。

8輸出 PDF / 列印（A3 分頁拼貼）

  1. 按工具列「列印 / 匯出 PDF」。
  2. 目的地選「另存為 PDF」（或直接選印表機），紙張 A3、橫向。
  3. 按「儲存」或「列印」。檔名自動帶表單標題與日期時間。

自動分頁設計（字體以肉眼可讀為準，不硬塞一頁）：

  • 時間軸自動切成多頁：第 1 頁含表頭資訊與左側步驟表，第 2 頁起是時間軸的無縫接續（2 循環約 2 頁、6 循環約 5~6 頁）
  • 每頁上緣標示「第 N 頁｜時間範圍」；印出後沿邊裁切、依時間軸對齊拼貼，即成完整 SWCS 大圖（可張貼於現場）
  • 字體已自動放大，A3 印出後表格文字與秒數標籤清楚可讀
  • 統計表（各循環 CT、人等機、機等人明細）附在最後

9儲存與開啟資料檔

  • 儲存資料檔：跳出「另存新檔」視窗，可選資料夾與檔名（預設 SWCS_產品名_日期時間.json，每次都是新檔不互相覆蓋）。
  • 開啟資料檔：選擇 .json 檔載入完整資料與圖形。
  • 要把自己的案子傳給別人：存出 json，連同工具 html 一起寄，對方用「開啟資料檔」載入。
